Single Event (Dis)assembly

Enter the raw bytes of a MIDI 1.0 event, then attempt parsing and disassembly.

Schema
Delta
Finalise
Readable
Parse an event to begin.

This utility is mainly for developers. If you are familiar with MIA and Mane, this can also be used as a very versatile parameter editor like XG Editor, GS Advanced Editor and Korg X5/N5 editor, basically (Neo)Vim, SCORE or LilyPond for MIDI.
