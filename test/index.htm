List of Octavia demos

Read the usage notice first. Additional documentations are available.

Octavia also offers a series of tools for convenience, as well as demos for legacy systems (Firefox 52 ESR and Chrome 59).

Routers

  • Coloratura (WIP; full player and routing suite; learn more)
  • Splash (lightweight routing and debugging instrument; learn more)
  • Middleware (old) (router; bug fixes only)

Visualisers

  • Cambiare (visualiser and debugging instrument, lazy pixel blur; learn more)
  • Emulated YAMAHA MU screen (full pixel blur) (minimal)
  • Emulated Roland SC screen (lazy pixel blur by default) (minimal)
  • Emulated KORG NS5R screen (lazy pixel blur by default)
  • Emulated YAMAHA QY screen (no pixel blur)
  • Emulated YAMAHA PSR screen (full pixel blur)
  • Emulated Roland SC-8850 screen (lazy pixel blur by default)

Additional Applications

  • Candy (WIP; universal synth editor; learn more)
  • Dawn (WIP; macro-level file manipulator; learn more)
  • Simulacris (WIP; bitmap SysEx editor; learn more)

Abandoned

  • Text UI (deprecated due to security vulnerabilities)

Usage notice

Demos of Octavia (not Octavia itself) are all under CC BY-NC-SA 4.0 license. Credits are advised when Octavia demos are used for recording videos. Demo MIDI files came along with Octavia demos are all credited here.

Some demos may require loading additional SysEx sound sets, and can either be included in the demos themselves, or be downloaded elsewhere. Demo 7 require JayB's X5D(R) sound set and NS5R sound set to be loaded, which can be downloaded from jaybmusic.net.

Octavia does not embed MIDI synthesizers currently, so please prepare your own pre-rendered audio files if you wish to see Octavia in action. If you wish to experience full MIDI bitmap animation experience, please watch them in demo screens with pixel blurs.
